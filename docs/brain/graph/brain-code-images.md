# brain code takes images: drop, paste or Alt+P attach them, and the conversation shows them

Images reach a brain code session three ways, all through one attach path: drop a file on the window, paste one, or
Alt+P, which opens the brain file explorer. Several images can go with one message; they wait in the composer as
thumbnails that can be removed, and go to the session as image blocks, the way a terminal paste does. The conversation
shows them as thumbnails that open in the one image viewer, as mermaid diagrams do.

## Why
In a terminal a dragged image only shows as "[Image #1]", and the user wants to see his images in the chat.
