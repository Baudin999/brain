# A conversation's agent is the open agent; the window is just another terminal

The agent that brain serve starts for a sitting is the same open agent as `claude --agent brain` in a terminal: the same agent file, role, tools, hooks and rules. It talks with the user, reads the code and the graph, searches the web, sends builders and validators after the readiness check, and never implements. There is no separate conversation agent and no lesser variant of it. What differs is only the surroundings: the window instead of a terminal, and the server, not any session, writing the trail.

## Why
In the user's words: "the conversation agent IS an open agent. Working through the brain interface is exactly the same as spinning up claude code in a terminal." Treating a sitting as its own kind of agent kept producing a weaker, separate role that drifted from the open agent.
