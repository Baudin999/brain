# Each project has its own color: the same spot on the wheel, adapted to the theme

A project's hue comes from its name alone, so it is the same on every machine and adding a project changes no other project's color. The active Omarchy theme sets lightness and saturation, so the colors fit whichever theme is on and follow a theme switch, and every color stays readable against the window. Without Omarchy, brain's own light and dark theme sets them the same way. The palette has no end: any number of projects gets a color, and two projects landing close in hue is acceptable.

## Why
The user loves visual cues, and colors are at the root of that, so a project should be recognisable by color wherever it shows. The colors have to be consistent to be learned. A fixed color per project would clash with some themes, so the user chose the same spot on the wheel, adapted to the theme.
