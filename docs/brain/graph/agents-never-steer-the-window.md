# Agents never steer brain's window: the user finds what he works on himself

An agent in brain's window, the chat included, can talk about a method, a node or a problem, but it never opens, selects or scrolls to anything on the user's screen. When the agent and the user agree on what to work on, the user finds it himself, which is why the window's lists need search. In the Navarone tab this shapes the Signals flow: one row per method with its signals under it, and a search box on method names, the same for a review and a cleanup, since both are finding something and then fixing it.

## Why
The user: "I am afraid that if agents can control pages in brain's ui, I will get pulled left and right in the middle of my flow."
