# The workspace renders markdown with mermaid, and shows code plain until Navarone gives it context

Markdown reads well, mermaid included, and links between files are followed. Code is not highlighted the standard way. In the user's words: "I do not care that something is a keyword, I care how a method is structured!" Until Navarone gives highlighting its context, code shows plain in a good monospace font, and later the lens shows what a highlighted function actually is.
