# brain's window and the workspace draw from one stylebook, served to both and held by one gate

`tokens.css` and `components.css` live in a shared place both surfaces serve. Workspace-only components, like a tree row, join the same components sheet and the same Stylebook view. One gate holds the sheets and scripts of both surfaces, so the two looks cannot drift.
