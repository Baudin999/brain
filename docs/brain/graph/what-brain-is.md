# Brain is the memory the user and Claude share, so each conversation starts where the last one left off

Brain holds what is worth knowing and not worth working out again. The personal scope holds who the user is: how they think, what they like, what they mean by their words. The global scope holds general information: how we work together, the tools and the models. A project scope, in the project's docs/brain, holds functional and technical information: what the project does and why it is shaped that way. Ideas live here too, as larger documents that summarise a conversation: what we discussed, what we rejected, and the reasons behind an idea. They are the trace of the user and Claude being creative together.

Brain is not a work log, a plan or a project management tool. Git holds what happened and the conversation holds the plan. A document in brain is true now; when it stops being true it is edited in place and git keeps the old text.

The test for a write: would a fresh Claude, without this, misunderstand the user or redo a thought we already had? If not, it is noise, however true. The store belongs to the user: they read it, argue with it and correct it.

## Why
Without a shared memory every session starts from zero: it misunderstands the user and repeats thinking already done. Code and git already answer what was built and when, so the store keeps only what they cannot: who the user is, why things are shaped as they are, and where our thinking went.
